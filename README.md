# SMW Central ROM Archive

- [Support](#Support)
- [Contributing](#Contributing)

This tool downloads all Super Mario World ROM's that are uploaded to [smwcentral.net](https://www.smwcentral.net/) in the awaiting moderation section and archives them for download.

The main purpose of archiving the waiting section is because good hacks are deleted if the moderator feels offended in any way by text, images, or sounds.

> [!TIP]  
> Patch and Play ROM's in the Browser with a single click using the [SMWC Web Extension](https://github.com/cssnr/smwc-web-extension?tab=readme-ov-file#readme)!  
> Download from: [Chrome Webstore](https://chromewebstore.google.com/detail/smwc-web-extension/foalfafgmnglcgpgkhhmcfhjgmdcjide) or [Mozilla Addons](https://addons.mozilla.org/addon/smwc-web-extension)
